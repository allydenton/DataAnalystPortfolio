# DataAnalystPortfolio

This repository serves as a final project for SIS-750, with the goal of creating a data analyst portfolio. 
It includes four main components:
  1) A revised original research project examining changes in electoral democracy over time. This project evolved from a visualization-based analysis into a full slide deck. The final project, titled Democratic Backsliding in Latin America, is [here](https://github.com/allydenton/DataAnalystPortfolio/tree/3a888db103c2ec39670f8fc85f90f974fa973a2d/PS2-Portfolio-Version). 
  2) A second revised original research project analyzing the relationship between wealth and dimensions of national power. This project uses expanded and refined visualizations to communicate cross-national patterns more clearly. You can view this work [here](https://github.com/allydenton/DataAnalystPortfolio/tree/3a888db103c2ec39670f8fc85f90f974fa973a2d/PS4-portfolio-version).
  3) An [exemplary code chunk](https://github.com/allydenton/DataAnalystPortfolio/tree/3a888db103c2ec39670f8fc85f90f974fa973a2d/Code-Chunk) demonstrating the development of an R function used to generate grouped summary statistics tables.. 
  4) A [data analyst resume](https://github.com/allydenton/DataAnalystPortfolio/blob/3a888db103c2ec39670f8fc85f90f974fa973a2d/Denton_DataAnalystResume.pdf) ailored to the technical and analytical skills developed throughout the course. 

This portfolio demonstrates applied experience in reproducible data analysis, statistical modeling, and data visualization using R across political and economic datasets.
