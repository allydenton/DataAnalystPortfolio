# Introduction to the Project

This project builds on earlier work completed for a Data Analysis (SIS-750) assignment focused on telling a story through visualization. 
The research examines patterns of democratic backsliding globally, with a more detailed focus on selected Latin American cases. 
Using a combination of maps and trend lines, the project explores how levels of electoral democracy have changed over time.

The analysis relies on the Electoral Democracy Indicator (`v2x_polyarchy`) from the [Varieties of Democracy dataset](https://www.v-dem.net/data/the-v-dem-dataset/). 
The V-Dem dataset is a large, multidimensional resource that measures different aspects of democracy across countries and over time, going beyond simple indicators like the presence of elections to measure change in electoral democracy over time (2010-2023). 
Due to its size, the full dataset is not included in this repository.

The approach to this project is structured in two main stages. 
First, the data are cleaned and filtered to focus on the `v2x_polyarchy` variable and the 2010-2023 time period. 
The analysis then begins with a global perspective, using summary statistics and a map to visualize changes in electoral democracy across countries. 
Please note that the map may be missing some countries due to naming issues. 

After establishing this broader context, the project narrows in on four Latin American cases: Venezuela, El Salvador, Brazil, and Ecuador. 
For these cases, the analysis uses summary statistics and a time series visualizations to examine trends in electoral democracy and identify patterns of democratic decline or stability over time.
